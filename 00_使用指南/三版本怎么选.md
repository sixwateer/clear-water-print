# 三个版本怎么选

本项目提供三个可实际使用的版本，外加一个可选后端。它们共用同一套修复思路，但使用方式不同。按你的场景选一个即可。

## 一览对比

| 维度 | HTML 普通版 ⭐ | HTML 进阶版 | Skill 版 | 小程序版 |
|---|---|---|---|---|
| 位置 | `02_HTML版/…普通版…html` | `02_HTML版/…对接后端版.html` | `03_Skill版/` | `04_小程序版/` |
| 使用方式 | 双击打开网页 | 网页 + 本地后端 | WorkBuddy 对话 | 微信开发者工具/手机 |
| 是否要安装 | 完全不用 | 要装 Python 依赖并启动服务 | 导入 `.skill` 包 | 要装微信开发者工具 |
| 是否联网 | 不用 | 不用（本地服务） | 不用 | 不用（本机处理） |
| 修复算法 | 纯前端拉普拉斯/填充 | 可接 AI（LaMA/ESRGAN） | Python 本地算法 | 纯前端拉普拉斯/填充 |
| 复杂背景效果 | 一般 | 好（接后端后） | 中 | 一般 |
| 适合 | 绝大多数普通场景 | 追求专业效果 | 批量/对话式处理 | 移动端体验 |

## 选择建议

### 选 HTML 普通版，如果……
- 你只是想去掉自己几张图片的水印；
- 你不想装任何软件、不想配置环境；
- 你的图片背景是纯色、渐变或比较柔和的（这是最常见的情况，效果也最好）。

**这是绝大多数人的选择。**

### 选 HTML 进阶版，如果……
- 普通版效果不理想，图片背景很复杂（照片、纹理）；
- 你愿意花几分钟启动本地 AI 后端（有 NVIDIA 显卡效果更佳）；
- 你需要视频时序修复、源头解析等高级能力。

### 选 Skill 版，如果……
- 你经常要处理图片，希望在 WorkBuddy 对话里说一句「去掉这张图的水印」就完成；
- 你想批量处理，或把去水印集成到自己的工作流里；
- 你能接受命令行/脚本方式。

### 选小程序版，如果……
- 你想在手机上处理图片；
- 你打算把它发布成自己的微信小程序；
- 你有微信开发者工具，或愿意安装它来体验。

## 组合使用

这三版不是互斥的。常见组合：
- **日常用普通版**（快），遇到难处理的图**临时启动后端用进阶版**（效果好）。
- **Skill 版**用于自动化/批量，**普通版**用于临时手动处理。
- **小程序版**作为移动端入口，算法和交互逻辑可参考 `utils/inpaint.js` 移植。
