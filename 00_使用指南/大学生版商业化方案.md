# 净像图片修复 · 大学生版商业化方案（零服务器）

> 目标人群：大学生（18–24 岁）
> 技术前提：**纯本地处理，不搞服务器、不上传图片**。现有 `04_小程序版` 已完全满足。
> 这份方案取代通用版的"付费会员/AI 上云"思路——那些对大学生既没必要，也和本地隐私卖点冲突。

---

## 0. 一句话定位

**"学生党专用的图片修复工具：证件照、PPT 截图、朋友圈配图，一键去掉瑕疵和标记，图片不上传，免费又隐私。"**

三句话讲清差异：
- 别人家的工具要上传图片到服务器——**你不上传**，照片留在手机里（隐私卖点，也是审核友好话术）
- 别人家功能大而全——**你只做学生高频的几件事**，快、简单、免费
- 你零服务器成本，所以可以**完全免费 + 广告变现**，对价格敏感的学生最友好

---

## 1. 为什么"大学生 + 本地处理"是绝配

| 大学生特点 | 你的对应优势 |
|---|---|
| 钱包紧、付费意愿低 | 免费 + 看广告解锁，比卖会员更现实 |
| 照片隐私敏感（证件照、自拍） | 本地处理不上传，天然信任 |
| 社群密集（班群、社团、表白墙） | 传播成本低，冷启动 100 UV 很快 |
| 内容平台活跃（小红书/B站/抖音） | 一篇教程笔记就能带来长尾流量 |
| 用图片场景集中且高频 | 场景模板能精准命中，不用做万能工具 |

## 2. 大学生高频场景（产品功能规划的核心）

| 场景 | 学生具体在做什么 | 用什么框架 | 可做的功能 |
|---|---|---|---|
| **证件照/简历照** | 去掉照片上的日期戳、背景杂物、旧标记 | 智能扩散/快速填充 | 场景模板：预设小框+智能扩散 |
| **PPT/网课截图** | 去掉素材图上的水印、页眉页脚标识 | 智能扩散 | 场景模板：预设矩形+智能扩散 |
| **朋友圈/社交配图** | 去掉图片上的标记、划线、贴图 | 纹理重建 | 场景模板：中框+纹理重建 |
| **表情包/梗图** | 去掉原图表情包的平台标记 | 纹理重建 | 通用框选即可 |
| **课程资料/论文截图** | 去掉截图上的水印、页码标记 | 智能扩散/快速填充 | 通用框选即可 |

**关键合规红线**：这些场景都必须是"学生自己的图 / 已获授权的图"。
**绝不能**把产品包装成"去任意平台水印工具"——那既过不了审，也有法律风险。
界面上统一说"去掉图片上的标记/瑕疵/日期戳"，不要说"去水印"。

## 3. 核心功能规划（全部本地可实现，不碰服务器）

### 3.1 已具备（保持不动，这是地基）
- 矩形框选 / 线条去除（闭合轮廓内修复）
- 五种修复框架：智能扩散 / **文字水印** / 纹理重建 / 快速填充 / 提示词引导
- **文字水印框架（新增）**：专为水印相机类打卡照片设计，只修复文字笔画、保留背景光影，不留矩形补丁——正好命中"图书馆打卡照去时间地点水印"这一学生高频场景
- 提示词引导（自然语言描述目标；写"水印相机/打卡/时间戳"自动推荐文字水印框架）
- 8 手柄缩放、选中拖拽、撤销清除、换图
- 保存到相册、用户协议与隐私政策页
- 全部本地运算，图片不上传

### 3.2 建议新增（P1，提升大学生体验，仍是纯本地）
| 功能 | 做法（不搞服务器） | 价值 |
|---|---|---|
| **场景快捷入口** | 首页加 3 个预设按钮：证件照 / 截图 / 配图。点一下自动设好默认框架和框大小，用户只管拖框 | 降低上手门槛，学生一眼知道自己能用它干嘛 |
| **最近修复（本地缓存）** | 用 `wx.setStorageSync` 存最近 5 张的缩略图和参数（只存本地） | 提升复访，也是广告展示的自然节点 |
| **修复前后对比分享** | 生成对比图保存到相册，学生自己发朋友圈/小红书 | 免费的自传播，注意：不可做"分享解锁" |
| **批量处理** | 本地队列依次处理多张图 | 处理证件照/一套素材时省事 |

### 3.3 明确不做（和"零服务器"冲突）
- AI 深度修复（需上传图片到后端）
- 云同步 / 账号会员体系（需服务器，且学生数据沉淀弱、做会员无意义）
- 任何需要 AppKey、API 调用的能力

## 4. 盈利模式（针对大学生，按优先级）

### P0 — 流量主广告（主收入）
- **门槛**：累计 100 UV（2026 已降门槛），个人主体可开，无违规即可
- **为什么最适合学生**：学生接受"看广告换免费"，比直接付费意愿高得多
- **接入方式**：后台"智能接入"可零代码上线；或代码接入
- **广告位策略（别伤体验）**：
  | 阶段 | 广告位 | 说明 |
  |---|---|---|
  | 刚开通 | 原生模板 / Banner（底部） | 不遮挡核心功能，先跑数据 |
  | 有数据后 | 激励视频（可选） | 设计成"看15秒广告解锁批量处理/高级框架"，用户主动选择才不伤留存 |
- **收益现实**：日活 1000 量级，广告日收入多为几元到几十元。当成"验证需求+拿数据"。

### P1 — 赞赏（0 抽成，补充收入）
- 个人小程序支持"喜欢开发者"按钮，平台抽成 0
- 文案贴合学生："觉得好用？请作者喝杯奶茶"，比生硬"打赏"自然
- 入口克制，放在"处理完成"页，别做成逼打赏

### P2 — 虚拟支付（可选，谨慎）
- 2026 新规：个人主体 + 工具类别目 + 认证备案可开，月限额 10 万
- **但**：大学生付费意愿低、iOS 还有 12% 苹果佣金且账期 45–60 天
- **建议**：先不做。等有了稳定流量，再考虑低价单次解锁（1–3 元），且主要靠 Android

### 变现组合结论
**广告为主 + 赞赏为辅 + 虚拟支付观望**。零服务器、零成本、零合规负担，最贴合学生群体。
