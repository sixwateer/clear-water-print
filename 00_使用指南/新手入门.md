# 新手入门（完全不需要专业知识）

这份指南假设你**从来没用过命令行、不懂编程**。只要会用浏览器，就能去掉自己图片上的水印。

## 最省事：打开一个小程序/网址就能用

**手机、平板、电脑都能直接打开，不用下载任何东西：**

<https://sixwateer.github.io/clear-water-print/>

- 微信里点开链接后，建议点右上角「···」→「在浏览器打开」，框选和保存都会更顺手。
- 图片只在你自己的浏览器里处理，**不会上传到任何服务器**。
- 手机上的手势：手指拖动画出选框 → 拖选框四角/四边的小方块缩放 → 拖框内部移动位置。
- 保存：点「下载修复结果」。iOS 上如果没进相册，会弹出图片预览，**长按图片 → 存储到照片**即可。

想完全离线、不依赖网络，就用下面的本地双击版。

## 最快的方法：双击打开就能用

1. 打开文件夹 `D:\去水印\02_HTML版`。
2. 找到文件 **`净像去水印_普通版_双击即用.html`**，**双击**它。
3. 它会用你的浏览器（Chrome / Edge 都可以）打开一个页面。

> 想先看效果？直接点页面里的蓝色按钮「**没有图片？点我用内置示例体验**」，不用准备任何图片。

## 四步去掉水印

**第 1 步：上传图片**
- 把你的图片**拖到**页面中间的虚线框里，或者点一下虚线框选择图片。
- 只支持图片（JPG / PNG / WEBP）。图片不会上传到网上，只在你电脑里处理。

**第 2 步：框住水印**
- 在出现的图片上，**按住鼠标左键拖动**，画一个框把水印圈起来。
- 框得贴合水印，效果越好。每次只保留一个框：重新画框会替换掉上一个。
- 画错了？点工具栏的「撤销一个框」或「清除全部」。

**第 3 步：点修复**
- 勾选右下角的「我确认这张图是我自己的，或已获得处理授权」。
- 点绿色的「**开始修复**」按钮。等几秒钟。

**第 4 步：看效果、下载**
- 页面会跳到对比区，**拖动中间的白线**就能左右对比修复前后。
- 满意就点「**下载修复结果**」，图片会存到你的下载文件夹。
- 不满意？点「处理下一张」重来，或换一种修复方式再试。

## 修复方式怎么选（选不懂就用默认）

| 选项 | 什么时候用 |
|---|---|
| 智能修复（默认） | 背景是纯色、渐变、比较柔和的（最常见，推荐） |
| 快速填充 | 水印很小、背景很单一，想要最快 |
| 纹理平移 | 背景是重复图案，比如草地、砖墙、条纹 |

## 常见问题

**Q：我的图片处理完有方块痕迹？**
A：这是纯前端算法的正常局限。试试：① 把框画得紧贴水印；② 换「智能修复」；③ 复杂照片背景请用「进阶版 + 后端」（见 README）。

**Q：会不会上传我的图片？**
A：不会。普通版是纯前端，图片全程只在你的浏览器里，页面代码里没有任何上传功能。

**Q：支持视频吗？**
A：这三个版本都只处理图片。视频去水印属于进阶能力，见 `01_文档资料` 里的方案文档。

**Q：手机上能用吗？**
A：普通版 HTML 在手机浏览器也能打开，但框选手感一般。想要手机体验，用 `04_小程序版`。

请只处理你自己创作或已经授权的图片。去掉水印不代表你拥有了这张图的版权，不要用它去掉别人的署名或平台标识。
