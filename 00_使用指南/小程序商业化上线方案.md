# 净像图片修复 · 小程序商业化上线方案

> 目标：把现有 `04_小程序版` 发布上线并产生收入。
> 现状：代码已完成（纯本地处理、三模式修复、线条去除、合规文案与隐私页齐备），
> 当前仍是游客 AppID（`touristappid`），尚未注册正式小程序账号。
> 本方案基于 2026-11 核实的微信平台规则；政策以小程序后台实际提示为准。

---

## 0. 决策摘要（先看这一段）

| 关键结论 | 说明 |
|---|---|
| **最快变现路径** | 流量主广告（100 UV 门槛）+ 赞赏（0 抽成）——都零代码/低代码、与"本地处理不上传"话术零冲突 |
| **付费解锁可行** | 2026 新规：个人主体 +「工具」类目 + 认证备案即可开**虚拟支付**，月限额 10 万；Android 手续费 1%，iOS 12%（苹果佣金，账期 45–60 天） |
| **最大风险不是技术** | 是"去水印"合规——名称/简介/界面/审核话术必须全程用"图片瑕疵修复、自有或已授权图片"，现有代码已按此改造，别自行改回敏感词 |
| **AI 上云要谨慎** | 你已有后端 AI 引擎。一旦接入，图片需上传，与"本地处理、不上传"过审话术冲突，且增加服务器成本与隐私合规负担——建议列为远期，且需单独改隐私指引 |
| **收入预期要现实** | 工具类用完即走，广告是长尾生意：日活 1000 量级，广告日收入多为几元至几十元。先当"验证需求 + 拿数据"，别按月入过万规划 |

## 2. 阶段规划（P0 必做 / P1 重要 / P2 增强）

### 阶段一：上线准备（P0）

| 项目 | 内容 |
|---|---|
| **任务** | ①注册小程序账号并实名 ②微信认证 30 元 ③ICP 备案 ④设类目「工具→图片处理」⑤填隐私指引 ⑥填 AppID ⑦真机自测 |
| **优先级** | P0——不做完无法提审 |
| **所需材料** | 本人身份证、本人微信（永久管理员）、未被占用的邮箱、银行卡（收款用，认证主体同名）、小程序名称与头像、简介文案 |
| **关键实现工作** | 代码侧已就绪：`project.config.json` 的 `appid` 从 `touristappid` 换成真实 AppID；确认界面无"去水印"字样（已有）；隐私页 `pages/privacy` 已备 |
| **风险点** | ①管理员微信不可随意更换（备案人脸核身用它）②备案需数日到数周，尽早启动 ③个人主体小程序上限 5 个 ④名称被占用需启用备选 |
| **验收标准** | 后台能看到 AppID；开发者工具真机预览走通"选图→框选→修复→存相册" |

> 详细逐步操作见同目录《微信小程序发布指引.md》与《微信小程序发布教程.html》，文案已备好可直接抄。

### 阶段二：上线与冷启动（P0）

| 项目 | 内容 |
|---|---|
| **任务** | ①上传代码 ②提交审核 ③发布 ④下载小程序码 ⑤凑够 100 UV 累计访客 |
| **优先级** | P0 |
| **所需材料** | 审核描述文案（指引里已备）、功能页面路径 `pages/index/index`、测试账号填"无需" |
| **关键实现工作** | 提审前再核对：名称/简介/描述/界面四处均无"去水印、解析、抖音"等敏感词；后台隐私指引已提交 |
| **风险点** | ①审核 1–7 工作日，可能要求在补充说明里强调"仅处理自有图片、本地处理、不上传不分享" ②冷启动 100 UV 是累去重的真人数，不可刷量/诱导分享，否则资格收回 |
| **验收标准** | 小程序可搜索到；后台累计 UV ≥100 且无违规 → 次日后台「推广→流量主」入口出现 |

### 阶段三：变现接入（P1）

| 优先级 | 模式 | 实现工作 | 材料/门槛 | 风险点 |
|---|---|---|---|---|
| **P1-首选** | 流量主广告 | 后台开通后可用"智能接入"零代码上线；或代码接入 `wx.createRewardedVideoAd` 等，先上原生模板/Banner 占位，跑 1–2 周数据再加激励视频 | 100 UV、无违规；补财务资料（本人银行卡、结算邮箱） | 别自点/互点、别诱导点击、广告别堆到影响核心功能 |
| **P1-补充** | 赞赏（喜欢开发者） | 放"喜欢开发者"按钮，用户自愿赞赏，平台抽成 0 | 个人小程序支持 | 入口要克制，别做成"逼打赏" |
| **P1-进阶** | 虚拟支付（功能解锁） | ①开放平台→支付与交易→虚拟支付→开通（5 分钟审核）②扫码签约 ③建道具（如"高级修复包 6 元""月度会员 18 元"）④代码内解锁逻辑 | 个人主体 + 工具类别目 + 认证备案；记下 AppID/OfferID/AppKey；月限额 10 万 | iOS 12% 佣金且账期 45–60 天，低客单价要算清；付费点不能是"解锁侵权能力" |

**付费点设计建议**（不得触碰"去除他人水印"）：
- 免费：基础三模式修复、每日若干次
- 付费：高级纹理框架、批量处理、大图无水印导出、历史记录云同步（后者需云服务）
- 不做：按"去水印张数"售卖、宣称可去任意平台水印

### 阶段四：增长与优化（P2）

| 项目 | 内容 |
|---|---|
| **任务** | ①广告位 A/B 测试 ②留存与复访优化 ③内容获客 ④报名成长计划拿曝光 |
| **优先级** | P2 |
| **关键实现工作** | 用后台数据分析"广告放哪不掉留存"；把工具做成"某一类人天天用"而非万能工具箱；公众号/小红书发使用教程带小程序卡片 |
| **风险点** | 工具类天然用完即走，留存低；别为收入牺牲体验导致留存与单价双输 |

### 阶段五：进阶验证（P2/P3，可选）

| 项目 | 内容 |
|---|---|
| **任务** | 评估是否接入你已有的后端 AI 引擎做"AI 深度修复"付费项 |
| **优先级** | P3——需先验证有真实需求再做 |
| **关键实现工作** | 图片上传链路、服务器成本与限流、隐私指引改版（声明上传范围与用途）、付费次数核销 |

## 4. 收益管理

| 事项 | 规则（2026 口径） |
|---|---|
| 广告结算 | 半月结：次月 1 日、15 日前分别结上月下半月/上半月；无最低提现门槛；结算后 3 个工作日发结算单 |
| 虚拟支付到账 | Android T+3；iOS 约 45–60 天 |
| 税费 | 腾讯代扣代缴个税，并代征增值税及附加；后台数字是**税前**，到卡为税后 |
| 收款账户 | 必须认证主体同名银行卡；结算单邮箱填常用邮箱 |
| 对账 | 结算按**收款主体**汇总，同主体多个小程序合并一张结算单 |
| 建议 | 单独建一张表记录：日期/渠道/曝光/点击/收益/到账状态；每月核对后台与银行流水 |
