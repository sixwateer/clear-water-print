# 详细使用说明

## 坐标说明

图片坐标原点在**左上角**，x 向右、y 向下，单位为原始像素。
可用 Pillow 获取尺寸：

```python
from PIL import Image
im = Image.open("图.png")
print(im.size)  # (宽, 高)
```

先用看图工具定位水印的左上角 (x, y) 和宽高 (w, h)。框选尽量贴合水印，效果更好。

## 命令行完整参数

```
python remove_watermark.py <输入图> <输出图> [选项]

--rects JSON        水印框数组，如 '[{"x":650,"y":520,"w":230,"h":60}]'
                    多个框：'[{"x":10,"y":10,"w":80,"h":30},{"x":300,"y":500,"w":120,"h":40}]'
--rects-file PATH   文本框，每行 "x,y,w,h"，# 开头为注释
--auto POSITION     自动框常见角落水印：bottom_right / bottom_left / top_right / top_left
--mode MODE         smart(默认) / inpaint / average / texture
--iter N            smart 模式迭代次数：120(快) / 320(标准) / 600+(精细)
--sharpen           轻度锐化，默认关闭
```

返回值：单行 JSON，`ok:true` 表示成功。

## 各模式原理与局限

- **smart（拉普拉斯扩散）**：把框内像素当作待解区域，框外作边界，反复用四邻平均迭代收敛。
  - 优点：纯色/渐变/柔和背景近乎无痕；不需要 OpenCV。
  - 局限：大面积高对比度水印（深底白字）可能有轻微残留；复杂纹理会偏平滑。
- **inpaint（OpenCV TELEA）**：基于快速行进法的图像修复，边缘连续性好。
  - 优点：复杂背景、细线水印效果佳。
  - 局限：需安装 opencv-python；大块区域可能留糊。
- **average（边缘平均色）**：取框四周平均色平铺。最快，适合小水印/纯色底。
- **texture（纹理平移）**：从框上方（或下方）复制同尺寸区域。适合重复纹理背景。

## 提升效果的技巧

1. **框紧一点**：只框水印本身，不要框进太多正常内容。
2. **多个小框优于一个大框**：分散的水印分别框。
3. **换模式对比**：smart 不理想时试 inpaint（有 OpenCV）或 texture。
4. **调迭代**：smart 效果不够精细时 `--iter 600`。
5. **保留原图**：输出到新文件，方便对比和重试。

## 常见问题

- **提示"无法解析 rects"**：检查 JSON 格式（双引号），或用 `--rects-file`。
- **inpaint 模式报错**：OpenCV 未安装，改用 `--mode smart`。
- **修复后有方块感**：换 `--mode inpaint`，或缩小框选范围。
- **图片太大处理慢**：smart 的迭代与框面积成正比，可降 `--iter`。
