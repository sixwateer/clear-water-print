# 净像 · 图片去水印 Skill

在对话中直接去除图片局部水印/文字/标志。核心是一个自包含脚本，用 Pillow + NumPy（可选 OpenCV）在**本地**完成修复，不上传图片、不依赖外部服务。

## 合规前置（必须遵守）

- **只处理用户有权处理的自有内容**（自己创作/已获授权）。
- 拒绝用于去除他人作品的署名、版权信息或平台强制标识。
- 若用户意图不明确，先确认用途合规再执行；去除水印不等于获得版权。

## 快速使用

先用 Pillow 查看图片尺寸，确定要去除区域，再调用脚本：

```bash
python scripts/remove_watermark.py <输入图> <输出图> --rects '[{"x":650,"y":520,"w":230,"h":60}]'
```

参数：
- `--rects` 水印框 JSON 数组，原图像素坐标（左上原点）。可多个框。
- `--rects-file` 文本框路径，每行 `x,y,w,h`，`#` 开头为注释。
- `--auto` 自动框常见角落：`bottom_right`/`bottom_left`/`top_right`/`top_left`。
- `--mode` `smart`(默认)/`inpaint`/`average`/`texture`。
- `--iter` smart 迭代次数，默认 320，精细可设 600+。
- `--sharpen` 轻度锐化。

脚本以单行 JSON 打印结果（含输出路径、尺寸、实际框、模式），据此判断成功与否。

## 修复模式选择

| 模式 | 适用 | 说明 |
|---|---|---|
| `smart` | 纯色/渐变/柔和背景 | 拉普拉斯扩散，近乎无痕，默认首选 |
| `inpaint` | 复杂纹理背景（需 OpenCV） | TELEA 算法，边缘连续性更好 |
| `average` | 小面积、单一背景 | 边缘平均色填充，最快 |
| `texture` | 重复纹理（草地/砖墙） | 从邻近区域平移纹理 |

## 工作流

1. **确认合规**：内容是否为用户有权处理。
2. **定位水印**：查看图片尺寸；用户给坐标则用之，否则可询问大致位置，或用 `--auto` 处理常见角落。
3. **选模式**：默认 `smart`；复杂背景且有 OpenCV 时试 `inpaint`。
4. **执行脚本**：输出到新文件（不要覆盖原图，便于对比）。
5. **回报结果**：告知输出路径与所用模式，建议用户查看效果；不合适则调整框或换模式重试。

## 依赖

必需：`Pillow`、`numpy`（通常已装）。可选：`opencv-python`（启用 `inpaint` 模式）。
缺依赖时优先用 `smart` 模式，不必安装 OpenCV。
