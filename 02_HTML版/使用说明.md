# HTML 版本使用说明

本目录有两个网页版本，都是单文件、零依赖。

## 版本一：普通版（推荐，双击即用）

**文件**：`净像去水印_普通版_双击即用.html`

- 双击用浏览器打开即可，无需安装、无需联网、无需后端。
- 图片全程在本机处理，不上传。
- 内置真实修复算法（拉普拉斯扩散 + 平均填充），对文字水印能彻底去除、不留残影，纯色/渐变/纹理背景均适用。
- 点页面里的「用内置示例体验」可立即看效果。

**使用**：上传图片 → 框选水印（点「自动框右下角」可一键框好再微调）→ 勾选授权 → 点开始修复 → 拖动白线对比 → 下载。

**最多三个框 + 线条自定义框**（两版通用）：

| 操作 | 做法 |
|---|---|
| 矩形框选 | 工具栏选「矩形框选」，在图上拖拽画框；可连续画，最多 **3 个** |
| 轮廓去除 | 工具栏选「轮廓去除」，沿目标画一圈（首尾自动闭合），区域内目标被**去除并按周边衣服/背景色还原**；画布显示实际轮廓线，不是矩形块 |
| 移动 / 缩放 | 拖框内部移动，拖四角/四边白色手柄缩放；画布上标「框1/框2/框3」 |
| 删除 | 「删当前框」只删当前选中的框；「清除全部」清空所有框 |
| 微调 | 方向键移动当前框 1px，Shift+方向键 10px |
| 满 3 个后 | 再画新框会替换当前框，不会超过上限 |

适合在角色设定图、拼图等多目标场景里分别框住 2~3 个区域。矩形框与闭合轮廓都走「去除+颜色还原」：轮廓方式沿你画的线条精确圈住不规则目标，去除后用周边衣服/背景色向外扩散还原（普通版用拉普拉斯扩散，后端版用 OpenCV TELEA）；两种方式都保证所选区域外像素不变。

**v1.1 改进**（对应自我测试 Issue #1~#7）：

| 改进 | 说明 |
|------|------|
| 贴边水印修复 | 边界采样改为"镜像到框外"，框贴图像边缘时不再把水印色当边界，边缘不发白 |
| 自动外扩 | 修复框按短边 6% 自适应外扩（3~12px），吃掉水印抗锯齿边缘与投影阴影 |
| 大框加速 | 短边 >96px 自动走多尺度扩散：700×600 从 1582ms 降到 ~50ms，且不卡页面 |
| 局部锐化 | 锐化只作用于修复区，未修复的原图区域逐像素保持不变 |
| 智能识别兜底 | 识别时采样矩形夹紧到画布内，避免贴边时 `getImageData` 越界报错 |
| 一键框选 | 新增「自动框右下角」按钮，省去手动拖拽 |
| 下载不覆盖 | 文件名带时间戳：`净像_修复结果_20261117_132530.png` |

**自测**：`08_自测/html/` 下有一键自测脚本（真实木纹图 6 个场景 × 3 模式，共 18 项断言），
`python prepare.py && node run.js` 即可复跑；问题清单见同目录 `ISSUES.md`。

**改配色/文案**：文件顶部 CSS 的 `:root` 变量（换肤）和 `<script>` 开头的 `CONFIG` 对象（文案、算法参数）。

## 版本二：进阶版（对接本地后端）

**文件**：`原始原型_对接后端版.html`

- 需要配合 `05_后端引擎` 启动本地服务，才能用 AI 引擎（LaMA / Real-ESRGAN）和双引擎融合流程。
- 未启动后端时会自动降级为本地演示（效果较弱）。
- 提供引擎选择、服务状态指示、无损标记等进阶功能。
- **与小程序版功能对齐**（v1.5）：修复框架四选一（智能扩散 / 纹理重建 / 快速填充 / 提示词引导）、
  提示词输入区（可一键填示例）、「换下一张照片」（保留框架/提示词/引擎/授权设置）、
  画布三手势（空白处画框 / 拖框移动 / 拖 8 向手柄缩放），并同样支持最多 3 框与线条自定义框。

**提示词示例**：

> 我要去掉的是框住的蓝色包（包蓝蓝.png 中人物的包），其余区域依据背景或人物衣物进行修改。

解析结果实时显示，并传给后端：`目标：蓝色包 · 按衣物/背景纹理补全 · 推荐「纹理重建」`。
选择「提示词引导」框架时，后端按解析结果自动选算法；留空则用智能扩散。

**处理约束**：默认 `strict_box=true`，后端把原图框外像素贴回结果图——
**框外逐字节不变，仅框选区域被去除并按背景/纹理补全**。结果区会显示本次使用的框架与约束状态。

**启动后端**：
```bash
cd 05_后端引擎
python -m pip install -r requirements.txt
python server.py
```
看到 `Uvicorn running on http://127.0.0.1:8000` 后，打开本 HTML 即可（右上角显示引擎可用）。
Windows 上也可以直接双击 `05_后端引擎/start.bat` 一键启动。

**自测**：`08_自测/html/test_backend_page.js` 用 Node 沙箱加载本页真实脚本，
验证框架解析、提示词、换图保留设置与后端参数传递（8 项）。

## 该选哪个

绝大多数情况用**普通版**即可。只有普通版效果不满意、且你愿意配置后端时，再用**进阶版**。详见 `00_使用指南/三版本怎么选.md`。

## 合规

两版均内置授权确认。仅用于处理你有权处理的自有内容。


## 文字 / 马赛克修复能力说明

算法优先做**笔画级去除**：只识别并修复文字/Logo 的笔画像素，物体表面的颜色、
纹理、光影、折痕完整保留；遇到纯色块或整片马赛克遮盖时，改用双线性插值重建该区域。
两种路径都严格只改框内像素，框外逐字节不变。

测试素材（`06_素材与示例/测试输入/`）：

- `test_text_mosaic.png`：文字 + 马赛克 + 深色底白字，验证彻底去除与背景重建；
- `蓝蓝和鲸鲸.png`：插画多 Logo，验证笔画级去除对物体纹理的保留。

**能力边界**：对水印、文字、马赛克覆盖的均匀/纹理背景，去除与重建效果良好；
对"印刷在复杂物体表面的 Logo"（如插画人物帆布袋上的字母），纯像素算法能显著淡化
或去除文字，但无法凭空重建被遮挡的语义纹理（折痕、图案），这部分需要生成式模型。


## 增强版（专去「豆包生成」水印 /「JJ」标记）

文件：`净像去水印_增强版_双击即用.html`（双击即开，零依赖，图片全程留在本机）。
在线版：https://sixwateer.github.io/clear-water-print/enhanced.html

用法：打开后点顶部「示例·豆包水印」或「示例·JJ 标记」会自动放好选框并选好模式，
直接点「开始修复」；也可「导入图片」后自己拖框。修复模式说明：

- **平滑背景**：虚化/纯色/渐变背景上的水印（如「豆包AI生成」）。整框插值，自动外扩避开文字边缘。
- **物体表面**：衣服、帆布袋、招牌、木牌上的实心字（如「JJ」）。只去笔画，保留物体纹理。
- **智能**：按框形状和文字明暗自动选上面两种。

拖动结果区下方滑块可对比前后，确认后点「导出 PNG」。检测力度分弱/中/强，
笔画漏检时调强，误伤纹理时调弱。
