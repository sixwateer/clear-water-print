# HTML 版本使用说明

本目录有两个网页版本，都是单文件、零依赖。

## 版本一：普通版（推荐，双击即用）

**文件**：`净像去水印_普通版_双击即用.html`

- 双击用浏览器打开即可，无需安装、无需联网、无需后端。
- 图片全程在本机处理，不上传。
- 内置真实修复算法（拉普拉斯扩散 + 平均填充 + 纹理平移），对纯色/渐变背景的水印效果好。
- 点页面里的「用内置示例体验」可立即看效果。

**使用**：上传图片 → 拖动框选水印（可多个框）→ 勾选授权 → 点开始修复 → 拖动白线对比 → 下载。

**改配色/文案**：文件顶部 CSS 的 `:root` 变量（换肤）和 `<script>` 开头的 `CONFIG` 对象（文案、算法参数）。

## 版本二：进阶版（对接本地后端）

**文件**：`原始原型_对接后端版.html`

- 需要配合 `05_后端引擎` 启动本地服务，才能用 AI 引擎（LaMA / Real-ESRGAN）和双引擎融合流程。
- 未启动后端时会自动降级为本地演示（效果较弱）。
- 提供引擎选择、服务状态指示、无损标记等进阶功能。

**启动后端**：
```bash
cd 05_后端引擎
python -m pip install -r requirements.txt
python server.py
```
看到 `Uvicorn running on http://127.0.0.1:8000` 后，打开本 HTML 即可（右上角显示引擎可用）。

## 该选哪个

绝大多数情况用**普通版**即可。只有普通版效果不满意、且你愿意配置后端时，再用**进阶版**。详见 `00_使用指南/三版本怎么选.md`。

## 合规

两版均内置授权确认。仅用于处理你有权处理的自有内容。
