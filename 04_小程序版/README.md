# 净像 · 图片修复（微信小程序版）

原生微信小程序版本，图片在本机处理、不上传。基于官方 `workbuddy-native-basic@1.0.0` 基线增量开发。

> **关于命名**：为符合微信小程序审核规范（"去水印"字样易被判定侵权风险），发布时统一使用"净像 · 图片修复"这一中性名称，功能不变——仍用于修复你有权处理的自有图片上的瑕疵/标记。类目选择「工具 → 图片处理」（个人主体可选）。详见 `00_使用指南/微信小程序发布指引.md`。

## 如何运行（普通用户）

1. 安装【微信开发者工具】。
2. 打开工具 → 导入项目 → 目录选择本文件夹 `04_小程序版`。
3. AppID 选择「测试号 / 游客模式」（配置里已填 `touristappid`），或填自己的小程序 AppID。
4. 点击「编译」，模拟器即可运行。
5. 手机预览：点工具右上角「预览」，扫码即可在手机体验（需联网预览，处理本身仍在本机）。

> 正式发布需替换为你的小程序 AppID 并在微信公众平台上传审核。工具内置"游客模式"足以本地体验和开发。

## 使用步骤

1. 点「选择图片」从相册选图或拍照。
2. 在图片上**按住拖动**框住水印；着急的话点「自动框右下角」，再用「框放大／框缩小」微调。
3. 选择修复方式（默认「智能修复」），勾选授权确认。
4. 点「开始修复」→ 预览结果 → 点「保存到相册」。

## 修复算法说明

- **智能修复 / 纹理修复**：整框拉普拉斯扩散（等价于传统 inpainting 扩散），从边界向内平滑重建，
  能彻底去除文字水印、不留残影，纯色 / 渐变 / 纹理背景均适用。
- **多尺度加速**：超过 240px 的大框先降采样扩散再双线性放大，速度提升数十倍，
  并保证扩散能到达框中心（避免大框中心留下初始色残痕）。
- **自动外扩**：修复时按框尺寸自适应向外扩 3~12px，覆盖水印的抗锯齿边缘与投影阴影，
  避免修复区边界留下白边。
- **快速填充**：取边框平均色平铺，速度最快，适合面积很小、背景单一的水印。
- 纯前端实现，无网络请求；对极端复杂背景（如人像发丝）效果有限，可用「进阶版 + 后端 AI 引擎」。

## 兼容性

- 图片选择：`wx.chooseMedia`（基础库 2.10+），老版本自动回退 `wx.chooseImage`。
- 离屏处理：`wx.createOffscreenCanvas`（基础库 2.16.1+），老版本自动回退页面隐藏画布。
- 触摸坐标：优先用 canvas 局部坐标；仅提供 `clientX/clientY` 的机型按画布位置换算，避免框选错位。

## 可替换/可配置项

- **换配色**：`app.json` 的 `navigationBarBackgroundColor` + `pages/index/index.wxss` 中的颜色值。
- **改文案**：`app.js` 的 `globalData.compliance`、`pages/index/index.wxml` 文本。
- **调算法**：`app.js` 的 `globalData.algo.smartIterations`（迭代越大越精细、越慢）；
  `utils/inpaint.js` 的 `MAXDIM`（多尺度阈值，默认 240）。
- **改外扩量**：`utils/inpaint.js` 的 `repair` 内 `grow` 计算（默认按框尺寸取 3~12px）。
- **换 logo**：在 `pages/index/index.wxml` 的 `.upload-ico` 区域替换为 `<image>`。
