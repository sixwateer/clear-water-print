# 净像 · 图片修复（微信小程序版）

原生微信小程序版本，图片在本机处理、不上传。基于官方 `workbuddy-native-basic@1.0.0` 基线增量开发。

> **关于命名**：为符合微信小程序审核规范（"去水印"字样易被判定侵权风险），发布时统一使用"净像 · 图片修复"这一中性名称，功能不变——仍用于修复你有权处理的自有图片上的瑕疵/标记。类目选择「工具 → 图片处理」（个人主体可选）。详见 `00_使用指南/微信小程序发布指引.md`。

## 如何运行（普通用户）

1. 安装【微信开发者工具】。
2. 打开工具 → 导入项目 → 目录选择本文件夹 `04_小程序版`。
3. AppID 选择「测试号 / 游客模式」（配置里已填 `touristappid`），或填自己的小程序 AppID。
4. 点击「编译」，模拟器即可运行。
5. 手机预览：点工具右上角「预览」，扫码即可在手机体验（需联网预览，处理本身仍在本机）。

> 正式发布需替换为你的小程序 AppID 并在微信公众平台上传审核。工具内置"游客模式"足以本地体验和开发。

## 使用步骤

1. 点「选择图片」从相册选图或拍照。
2. 在图片上拖动框住目标：
   - **空白处拖动** → 画新框
   - **拖框内部** → 移动框
   - **拖四角/四边的白色小方块** → 缩放框
   - 着急的话点「自动框右下角」，再用「框放大／框缩小」微调
3. 在「修复框架」里点选一种（可随时切换）。
4. 可选：填提示词，描述要去掉的目标和补全依据；点「用示例」可直接填入示例。
5. 勾选授权确认 → 点「开始修复」→ 预览 → 「保存到相册」或「换下一张照片」。

## 四种修复框架

| 框架 | 适用 | 做法 |
|---|---|---|
| **智能扩散**（默认） | 纯色 / 渐变背景 | 整框拉普拉斯扩散，从框外边界向内平滑重建 |
| **纹理重建** | 衣物、木纹、草地等纹理背景 | 扩散后从框外邻近背景行回注高频细节，避免糊成平色 |
| **快速填充** | 面积很小、背景单一 | 取边框平均色平铺，最快 |
| **提示词引导** | 想用自然语言描述 | 按提示词解析结果自动选上面三种之一；留空则用智能扩散 |

框架之间可随时切换，切换只影响下一次修复。

## 提示词怎么写

提示词明确两件事：**框住的目标是什么**、**空白处按什么补全**。

示例（点「用示例」一键填入）：

> 我要去掉的是框住的蓝色包（包蓝蓝.png 中人物的包），其余区域依据背景或人物衣物进行修改。

解析结果会实时显示在输入框下方：

```
目标：蓝色包 · 按衣物/背景纹理补全 · 推荐「纹理重建」
```

识别规则（纯本地，无网络请求）：

| 提示词里出现 | 补全依据 | 推荐框架 |
|---|---|---|
| 纹理 / 衣物 / 衣服 / 木纹 / 草地 / 条纹 / 褶皱 | 衣物/背景纹理 | 纹理重建 |
| 渐变 / 纯色 / 天空 / 白墙 | 周围背景渐变 | 智能扩散 |
| 背景 / 墙面 / 地面 / 周围 | 周围背景 | 智能扩散 |
| 快速 / 平均 / 小面积 | 边缘平均色 | 快速填充 |

## 处理约束：只改框内

这是本次的重点约束：**仅对框选目标执行去除，框外像素一个字节都不改。**

实现上，`repairStrict()` 先在原图副本上跑完整修复（含 3~12px 外扩），外扩区只作为扩散的**采样来源**用于覆盖抗锯齿边缘与投影；最后只把**原框范围内**的像素写回原图。因此：

- 框内能去净文字/标记，不留白边残影；
- 框外背景、人物、衣物完全保持原样；
- 纹理重建的高频回注采样行也在框外，同样不写回框外。

回归测试逐字节比对了框外所有像素，smart 与 texture 两种模式均通过。

## 其他算法特性

- **多尺度加速**：超过 240px 的大框先降采样扩散再双线性放大，速度提升数十倍，并保证扩散能到达框中心。
- **镜像采样**：贴边/贴角时无效采样点镜像到最近的框外位置，避免水印色成为边界条件导致修复区发暗。
- 纯前端实现，无网络请求；对极端复杂背景（如人像发丝）效果有限，可用「进阶版 + 后端 AI 引擎」。

## 兼容性

- 图片选择：`wx.chooseMedia`（基础库 2.10+），老版本自动回退 `wx.chooseImage`。
- 离屏处理：`wx.createOffscreenCanvas`（基础库 2.16.1+），老版本自动回退页面隐藏画布。
- 触摸坐标：优先用 canvas 局部坐标；仅提供 `clientX/clientY` 的机型按画布位置换算，避免框选错位。
- 手柄命中半径 18 CSS px，适配手指操作。

## 可替换/可配置项

- **换配色**：`app.json` 的 `navigationBarBackgroundColor` + `pages/index/index.wxss` 中的颜色值。
- **改文案**：`app.js` 的 `globalData.compliance`、`pages/index/index.wxml` 文本。
- **调算法**：`app.js` 的 `globalData.algo.smartIterations`（迭代越大越精细、越慢）；
  `utils/inpaint.js` 的 `MAXDIM`（多尺度阈值，默认 240）。
- **改外扩量**：`utils/inpaint.js` 的 `repair` 内 `grow` 计算（默认按框尺寸取 3~12px，仅用于采样）。
- **改提示词规则**：`utils/prompt.js` 顶部的 `RULES` 与 `EXAMPLE`。
- **换 logo**：在 `pages/index/index.wxml` 的 `.upload-ico` 区域替换为 `<image>`。
