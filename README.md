# 净像 · Watermark Studio

一个面向「本人有权处理的个人内容」（小红书、抖音等自有内容）的图片去水印与画质修复项目。提供 **HTML、Skill、小程序** 三个可直接使用的版本，外加可选的本地 AI 后端引擎。

> ⚠️ **合规声明**：仅用于处理你**有权处理**的自有内容。去除水印不等于获得版权，请勿用于去除他人作品署名或平台标识。各版本均内置授权确认。

---

## 🚀 普通用户：从这里开始（无需专业知识）

**只想去掉自己图片上的水印？** 直接看 [00_使用指南/新手入门.md](00_使用指南/新手入门.md)。

**在线版（手机 / 电脑浏览器直接打开，无需下载安装）：** <https://sixwateer.github.io/clear-water-print/>

最简单的用法：**双击打开 [02_HTML版/净像去水印_普通版_双击即用.html](02_HTML版/净像去水印_普通版_双击即用.html)** —— 不用安装任何东西，不用联网，图片只在你电脑里处理。上传 → 框住水印 → 点修复 → 下载，三步完成。页面里还有「用内置示例体验」按钮，可直接试效果。

**想把小程序正式发布到微信？** 看图文教程 [00_使用指南/微信小程序发布教程.html](00_使用指南/微信小程序发布教程.html)（双击浏览器打开，步骤卡片+文案一键复制+手机可看），或文字版 [微信小程序发布指引.md](00_使用指南/微信小程序发布指引.md)。

## 📦 三个版本怎么选

| 版本 | 位置 | 适合谁 | 是否需要安装 |
|---|---|---|---|
| **HTML 普通版** ⭐ | `02_HTML版/净像去水印_普通版_双击即用.html` | 普通用户、只想快速去水印 | 无需安装，双击即用 |
| **HTML 进阶版** | `02_HTML版/原始原型_对接后端版.html` | 追求更好效果、愿意启动后端 | 需启动本地后端 |
| **Skill 版** | `03_Skill版/watermark-remover/` | 想在 WorkBuddy 对话里直接处理图片 | 安装 `.skill` 包 |
| **小程序版** | `04_小程序版/` | 想在手机/微信里用 | 微信开发者工具 |

详细对比见 [00_使用指南/三版本怎么选.md](00_使用指南/三版本怎么选.md)。

## 🛠️ 进阶：本地 AI 后端（可选）

想要复杂背景的专业级修复？启动 `05_后端引擎` 的 FastAPI 服务，配合「HTML 进阶版」使用：

```bash
cd 05_后端引擎
python -m pip install -r requirements.txt
python server.py
```

后端采用双引擎融合：源头解析（无损）→ 反向 Alpha 混合（无损）→ AI 修复流水线 → OpenCV 兜底，失败自动回退。详见 [05_后端引擎/README.md](05_后端引擎/README.md) 与 [01_文档资料/双引擎融合架构与集成文档.md](01_文档资料/双引擎融合架构与集成文档.md)。

## ✅ 测试与验证

自动化测试可随时复跑，命令见 [08_自测/html/README.md](08_自测/html/README.md)。最近一次全绿结果：

| 目标 | 方式 | 结果 |
|---|---|---|
| HTML 普通版算法 | `node run.js`（从交付 HTML 抽取真实函数在 Node 执行） | **18/18** 断言通过（6 场景 × 3 模式） |
| HTML 普通版页面 | 无头浏览器跑完整流程（选图→框选→三模式→三档→整图框） | **10/10** 端到端通过 |
| 小程序版 | `node tests/test_new_features.js`（框架/提示词/手势/严格框内） | **9/9** 通过 |
| 后端核心流程 | `python tests/test_orchestrator.py` | **11/11** 通过 |
| 后端边界与异常 | `python tests/test_api_robustness.py` | **19/19** 通过 |

关键性能与质量指标：超大框 1582ms → **40ms**（多尺度扩散）；贴边场景边界色差 44.9 → **6.9**（镜像采样）；水印残影率修复后降至 **0**。

每个版本具体改了什么、为什么改，见 [CHANGELOG.md](CHANGELOG.md)。
