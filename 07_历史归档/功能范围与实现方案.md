## 三、核心实现要点

### 3.1 图片去水印（IOPaint LaMA）
- 部署：`pip3 install iopaint` 或本地源码；`iopaint start --model=lama`
- 批量：`iopaint run --model=lama --image=输入目录 --mask=掩码目录 --output=输出目录`
- 二次开发：抽 `iopaint/model/` 的 LaMA 封装成独立函数 `inpaint(image, mask) -> image`
- 保真关键：mask 外扩 2-5px 覆盖水印抗锯齿边缘；尽量缩小 mask 面积以保留细节

### 3.2 视频去水印（DeMark-World）
- 两阶段：YOLO 逐帧检测水印框 → LaMa（快）/ E2FGVI-HQ（时序一致无闪烁）修复
- 接入：Python API `DeMarkWorld(cleaner_type=...).run(input, output)` 或 REST Server 异步队列
- 音频：FFmpeg 分离音轨，处理后原样合并
- 保真关键：静态水印用 LaMa；动态背景用 E2FGVI-HQ 避免帧间闪烁

### 3.3 画质修复（Real-ESRGAN）
- 图片：`python inference_realesrgan.py -n RealESRGAN_x4plus -i 输入 --outscale 2`
- 视频：`inference_realesrgan_video.py`
- 人脸：`--face_enhance` 启用 GFPGAN
- 保真关键：去水印后**先修复再缩放**，outscale 不宜盲目放大（2x 通常足够）；提供 -dn 控制去噪强度避免过度平滑

### 3.4 源头解析（parse-video-py，可选优先通道）
- FastAPI/MCP 接口，输入分享链接，输出无水印原资源 URL
- 与 AI 通道的关系：解析成功 → 直接下载原图（零损失）；失败 → 回退 AI 修复
- 合规：仅在授权确认后启用，不做批量抓取

## 四、交付形态规划

### 形态 A · HTML 页面（推荐先做，作为交互原型与控制面板）
- **定位**：本地可打开的独立页面，作为整个工具的前端壳 + 算法调用控制台
- **技术**：单文件 HTML + CSS + 原生 JS（零依赖、易改），预留 `fetch` 接口对接后端
- **页面结构**：顶部导航 → HERO 上传区 → 处理流程状态条 → 框选编辑器 → 前后对比 → 参数面板 → 结果导出
- **视觉质感**：浅色高级感、柔和阴影、圆角卡片、渐变主色（青绿+靛蓝）、微交互动画、专业排版
- **可扩展**：配置驱动（主题色、步骤文案、算法参数集中配置），组件化注释清晰
- **产出**：`prototype/index.html`（本次已制作，见下）

### 形态 B · Skill（适合对话式调用）
- **定位**：封装成 WorkBuddy Skill，用户说"去掉这张图的水印"即可触发
- **能力**：接收图片路径 → 调用后端 API → 返回结果路径
- **结构**：`SKILL.md`（触发词、流程）+ `scripts/`（调用脚本）+ 依赖说明
- **适用**：轻量、单次、批量文件处理；适合后续做自动化流水线

### 形态 C · 小程序（适合移动端分享）
- **定位**：微信小程序，手机端上传图片/视频，云端处理
- **约束**：算力在云端（需部署后端服务），涉及隐私需明确授权；审核对"去水印"类目较敏感
- **建议**：作为远期形态；前期用 HTML 原型验证交互，再决定是否投入

### 形态选择建议
| 维度 | HTML 页面 | Skill | 小程序 |
|---|---|---|---|
| 开发成本 | 低 | 中 | 高 |
| 迭代速度 | 快 | 快 | 慢（审核） |
| 视觉质感掌控 | 高 | 中 | 中 |
| 算力承载 | 需后端 | 需后端 | 需云端 |
| 推荐时机 | **现在** | 第一阶段后 | 远期 |

**结论：先做 HTML 原型（已交付）→ 后端服务成型后封装 Skill → 视需求再评估小程序。**

## 五、落地路线图

1. **本周**：搭建后端骨架（FastAPI），本地跑通 IOPaint LaMA 图片擦除 + Real-ESRGAN 修复

## 六、风险与注意
- **画质权衡**：AI inpainting 必然有损，mask 越小越保真；优先源头解析通道
- **平台依赖**：解析接口易失效，需持续维护，作为增强而非核心
- **合规**：全程仅处理有权内容，产品内置授权确认与日志
- **算力**：GPU 显著加速（尤其视频 E2FGVI-HQ）；CPU 可跑但慢
- **许可证**：Apache-2.0 / BSD-3 / MIT 均友好，保留原始声明即可
